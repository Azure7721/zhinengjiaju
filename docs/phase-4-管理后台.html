Phase 4 · Admin

P4 · PC 管理后台

目标：让管理员能运营系统——建型号、管库存、查用户/家庭、配场景模板、看日志、审计、 用模拟器造信号。表单由 schema 生成，权限到菜单/按钮。

5–7 天 Vue 3 + Element Plus RBAC 动态表单 设备模拟器

1. 阶段目标

  • 管理员登录、布局、权限菜单
  • 仪表盘、用户/家庭、设备库存
  • 设备型号/能力/命令动态表单
  • 场景模板、日志、审计
  • 设备模拟器（发遥测/断连/错误）
  • 后台新增型号 → 小程序动态可见

2. 前置条件

P1 管理员登录/RBAC 可用；P2 设备/信号 API 可用。

3. WBS

时间任务产出
D1Vite + Vue3 + Element Plus；登录、布局、权限菜单空后台可登录
D2仪表盘：用户/家庭/设备/在线率/命令成功率指标可用
D3用户/家庭/住宅/房间；成员/角色/解绑运营查询
D4设备型号编辑器：能力/命令 schema + 预览可建型号

D6场景模板、遥测/命令/场景日志、审计可排查
D7设备模拟器、联调、权限/审计校验可运营

5. 动态表单与预览

  • 设备型号表单由 JSON Schema 生成；能力列表/命令参数用子表单。
  • 保存前 schema 校验；发布前可预览小程序控制区。
  • 版本化：已绑定设备保留旧元数据，新版本不破坏历史。
  • 复杂字段提供 JSON 编辑器 + 校验错误定位。

6. 设备模拟器

选型号→ 创建虚拟设备→ 发遥测→ 断连/错误→ 观察前端/日志

模拟器调用设备引擎，不直接改前端状态；用于演示与 T0 测试。

7. 验收标准

  • 四角色菜单/按钮不同
  • 新增型号并发布，小程序动态可见
  • 动态表单可编辑能力/命令
  • 库存可查绑定/解绑/迁移
  • 模拟器发遥测/断连，前端实时变化
  • 日志可筛选/详情
  • 越权 403，写操作有审计

8. 风险

  • 后台范围蔓延 → 只做运营必需，商城/内容后置。
  • 动态表单复杂 → 先支持基础类型，再补数组/嵌套。
  • 权限遗漏 → 以权限码清单逐页核对。
  • 日志量大 → 分页/索引/保留策略。

9. 下一阶段入口

P4 完成并与 P3 联调后进入 P5 · 联调与交付。
