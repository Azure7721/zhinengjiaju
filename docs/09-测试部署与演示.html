3. CI/CD

  1. install：pnpm install --frozen-lockfile。
  2. lint/typecheck：ESLint + tsc --noEmit。
  3. test：单元/集成；覆盖率门槛按模块设。
  4. build：server、admin、miniapp（mp-weixin）。
  5. e2e：启动 docker compose 测试栈，跑 Playwright。
  6. artifact：admin 静态包、server 镜像、miniapp 产物。

GitHub Actions 或本地脚本均可；关键是同一套命令在本地/CI 一致。

4.2 本机降级

  • winget/choco 安装 PostgreSQL、Redis（Memurai）、Mosquitto。
  • 或 SQLite + Aedes + 内存队列，仅开发/演示。
  • 所有端口、账号、路径写入 docs/phase-0 环境记录。

4.3 HTTPS / 小程序域名

  • 正式：备案域名 + 证书；配置 request/socket 合法域名。
  • 演示：开发者工具勾选“不校验合法域名”；真机用局域网 IP 或内网穿透（cloudflared/ngrok）。
  • 手机不能访问 localhost；必须用 PC 的局域网 IP。
  • WebSocket 用 wss；本地开发可 ws。

4.4 纯个人演示 · 零备案运行形态

个人演示、软件不挂公网服务器、不发布上线（仅开发版/体验版）时，全程零备案：

环节是否需要备案/资质说明
注册小程序拿 AppID不算备案个人主体身份证实名，免费；AppSecret 放后端环境变量
发布上线（他人可搜索）需要 ICP 备案 + 平台审核2023-09 起小程序上架前须备案——不发布即不触发
开发版/体验版演示不需要上传代码 → 微信号加为体验成员 → 扫码即用，免审核
后端不挂公网不需要域名/HTTPScode2Session 是后端主动调微信 API，微信不回访你的服务器

数据库 / MQTT不需要全部本机进程（P0 的本机服务/Docker 方案）

5. 日志、监控与备份

可观测

  • 结构化日志 + requestId；错误堆栈脱敏。
  • 健康检查 /health（DB/Redis/MQTT）。
  • 指标：在线设备、命令成功率、场景失败率、WS 连接数。
  • 管理后台展示关键指标与最近错误。

备份/恢复

  • PostgreSQL 每日备份；演示前手动快照。
  • 迁移可回滚；seed 可重置。
  • 图片/固件对象存储版本化。
  • 恢复演练至少一次。

6. 5–10 分钟演示脚本

0:00–0:40 管理后台

登录 → 设备型号/能力 → 展示“新增型号后小程序动态出现”。

0:40–1:40 小程序首页

家庭/环境/运行设备；3 秒指出运行设备；快捷开关反馈。

1:40–2:40 添加设备

扫描 → 连接 → 配网 → 绑定；回到首页看到新设备。

2:40–3:40 设备控制

空调/窗帘/电视/未知能力设备；命令 pending/success。

3:40–5:00 场景

观影模式执行，逐项状态；清洁模式进度。

5:00–6:00 能耗/我的

周/月切换、峰值、排名；家庭/成员统计。

6:00–7:00 后台日志

遥测/命令/场景/审计；展示绑定关系。

7:00–8:00 设备测试

T0 单机链路；如有硬件，切 T1 ESP32 BLE。

7. 发布检查清单

  • lint/typecheck/test/build 全绿
  • 数据库迁移与 seed 可重复
  • 设备绑定/解绑/迁移验证通过
  • T0 全链路通过；T1 至少 1.1–1.4
  • 权限/越权/限流检查通过
  • WS 断线重连、服务重启恢复通过
  • 体验版二维码可用，真机无白屏
  • 演示脚本一次走通，录屏备份
  • README/架构图/数据字典/已知限制齐全
