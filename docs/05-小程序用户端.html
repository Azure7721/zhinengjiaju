05 · Mini Program

小程序用户端

用户端负责“找设备、读状态、快操作、得反馈”。页面要贴合设计稿，但控制区必须由设备能力动态生成， 不能把四类设备写死成四套页面。

uni-app + Vue 3 Wot Design Uni uCharts Pinia 750rpx

1. 目标

  • 完成登录、首页、全屋、设备、场景、添加设备、消息、能耗、我的。
  • 设备详情按 capabilities 动态渲染；未知能力有降级控件。
  • 状态来自服务端/WS，刷新不丢；操作有 pending/success/failed。
  • 添加设备后出现在首页，并与账号/家庭绑定。
  • 核心体验验收：3 秒找到运行设备、操作 ≤2 步、每次操作有反馈。

2.1 入口盘点：空缺页面处理清单

设计稿有按钮但没有页面的入口，按 00 · UI 空缺入口处理规则 分两类处理：

入口 / 按钮出现位置归类处理方式
设置（账号安全、消息通知、通用、关于）我的 → 设置A 必要新设计页：分组列表 + 开关/表单，沿用现有风格，保留必要项
家庭管理（创建/切换/成员/房间）我的、登录后家庭选择A 必要新设计页：家庭列表、成员增删、房间编辑，接 P1 家庭/权限 API
设备编辑（改名/移房间/解绑/删除）设备详情 · 更多功能A 必要新设计页或弹层：三四个表单项，落库绑定关系
WiFi / 网络管理我的、配网失败引导A 必要新设计页：当前网络、重新配网入口，复用配网流程
退出登录我的 → 设置A 必要确认弹窗 + 清 token 回登录页
消息通知详情 / 告警处理消息列表A 必要列表项内跳转，告警可标记已读/跳设备
天气入口首页环境区A 简化静态数据或 mock，点开提示“演示数据”
发现（内容流、活动位）TabBarB 占位点击 toast「正在开发中」；Tab 保留
商城（商品、下单）TabBar、我的B 占位同上，不做内容与订单
健康生活（排行、打卡）首页/我的入口B 占位同上
会员卡 / 权益、耗材商城我的B 占位卡面可静态展示，点击「正在开发中」
第三方平台、个人服务运营位我的B 占位同上
  • A 类（必要/设置）：按现有 UI 风格新设计页面，只保留必要功能；每个页面控制在最小操作集。
  • B 类（丰富但无 UI）：统一用 feedback/UnderDev 占位组件，点击弹「正在开发中」；不做后端接口。
  • 开发中发现新入口按 00 的规则归类并回填本表。

3. 设计还原

尺寸与令牌

  • 设计稿 750×1624 JPG ≈ 375×812 @2x；小程序按 750rpx 写，1 设计 px ≈ 1rpx。
  • 主色青绿 #12BFC1；背景 #F2F7F8；卡片白。
  • 圆角 16–24rpx；阴影弱；字号按图分层。
  • 底部安全区 env(safe-area-inset-bottom)。

缺失素材

  • 产品图需透明底；没有就用同色底占位。
  • 图标用 iconfont/PNG；不用内联 SVG。
  • 字体用系统字体，按视觉调字重。
  • 渐变/阴影/毛玻璃按图试值，统一 token。

4.2 BLE 适配器

platform/ble 暴露统一接口：scan / connect / discover / read / write / subscribe / disconnect。通过环境变量切换 RealBleAdapter（uni BLE）与 VirtualBleAdapter（WebSocket），业务代码不变。

5. 关键页面

5.1 首页

  • 环境三指标（温度/湿度/空气质量）+ 家庭名 + 天气入口。
  • 房间 Tab（工作中/客厅/主卧/厨房/卫生间/餐厅），选中态明显。
  • 运行设备卡：模式、剩余时间、进度条；卡片主信息是状态。
  • 快捷开关：床头灯/音响；点击立即乐观更新 + 反馈。
  • 空状态：没有设备 → 引导添加；没有运行 → 显示环境与快捷入口。

5.2 全屋控制

  • 平面图底图 + 百分比坐标热点；点区域/标签同步高亮。
  • 环境/照明/监控分区；设备在线/运行/告警标识。
  • 快捷模式（清凉干爽/舒适宜人/温暖湿润）触发场景。
  • 小屏时平面图可缩放/滚动，不强行塞满。

5.3 设备详情

  • 头部：设备名、房间、在线状态、电源键。
  • 状态区：温度/PM2.5/开合度/模式，大字 + 单位 + 状态标签。
  • 控制区：按 capabilities 渲染；空调圆盘、窗帘滑杆、电视遥控、净化器模式。
  • 命令三态：pending（禁用+进度）、success（Toast/轻震）、failed（原因+重试）。
  • 更多功能：低频操作收进底部弹层，保持首屏清爽。

5.4 添加设备与配网

  1. 扫描：权限检查 → 扫描动画/进度 → 附近设备列表；空/失败给“确认电源/靠近设备”。
  2. 连接：倒计时 18s、步骤节点（数据发送/联网/添加）、可取消。
  3. 绑定：选家庭/房间/名称 → 写库 → 首页出现。
  4. 失败：token 过期、设备已绑定、超时、WiFi 失败，各有明确文案。

5.5 场景

  • 常用场景 chips；自动/手动标签；推荐/自定义分区。
  • 详情：执行区固定按钮、设备动作列表、触发条件、生效时间。
  • 执行：逐项状态（pending/running/success/failed），完成后汇总。
  • 清洁模式：进度/剩余时间/模式/配件选择。

5.6 能耗

  • 今天/本周/本月；uCharts 折线；峰值标注。
  • 电费、平均用电、碳排；设备排名进度条 + 占比。
  • 优化建议来自规则（如空调 26℃），不硬编码文案。

5.7 我的

  • 设备/运行/成员/WiFi 统计；家庭切换。
  • 入口分组：家庭管理、个人服务、设置。
  • 会员卡、二维码、耗材、第三方平台可静态。

6. 状态、实时与离线

Pinia Stores

  • device：设备、状态、在线、命令
  • scene：场景、执行、触发
  • energy：时间范围、聚合
  • user：登录、家庭、角色
  • ui：Toast、弹层、加载

实时与缓存

  • WS 订阅 device.state / device.telemetry / command.updated / scene.run.updated。
  • 断线重连 + 指数退避；重连后拉取全量状态。
  • 本地缓存最近状态；离线时只读并标记。
  • 命令乐观更新，失败回滚。

7. 验收

  • 微信 mock 登录 → 家庭选择 → 首页
  • 3 秒内找到运行设备及其状态
  • 首页到完成一次温度调节 ≤2 步
  • 四类设备可控，未知能力不白屏
  • 添加设备 → 配网 → 绑定 → 首页出现
  • 执行场景，逐项状态可见
  • 刷新/重连后状态不丢
  • 主流 iPhone/Android 不破版
  • 无控制台报错，关键操作有反馈
  • A 类空缺页（设置/家庭管理/设备编辑等）按现有 UI 风格可走通
  • B 类版块（发现/商城/健康生活/会员等）点击均提示“正在开发中”，无死按钮
